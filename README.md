# MiniChat

**MiniChat** — мобильное приложение-мессенджер для обмена текстовыми сообщениями.

Проект разработан в рамках практической работы по дисциплине **«Технологии разработки мобильных приложений»**.

## Цель проекта

Цель проекта — разработать мобильное приложение-мессенджер с возможностью регистрации и авторизации пользователей, просмотра списка чатов, обмена текстовыми сообщениями, поиска пользователей и управления профилем.

## Основные возможности

* регистрация пользователя;
* авторизация;
* выход из аккаунта;
* просмотр списка чатов;
* просмотр истории сообщений;
* отправка текстовых сообщений;
* поиск пользователей;
* создание нового диалога;
* просмотр профиля;
* локальное хранение истории сообщений;
* получение данных пользователей через REST API.

## Целевая платформа

* **iOS**

Разработка выполняется на **macOS** с использованием **Android Studio** и **Flutter SDK**.

# Архитектура

В приложении используется архитектурный паттерн **MVVM (Model–View–ViewModel)**.

Основная схема взаимодействия компонентов:

```text
View
  ↓
Riverpod
  ↓
ViewModel
  ↓
Repository
  ↓
Local Storage / REST API
```

### Основные уровни

**View**

Отвечает за пользовательский интерфейс приложения.

**ViewModel**

Содержит состояние экрана и логику взаимодействия между интерфейсом и данными.

**Repository**

Отвечает за получение и обработку данных.

**Local Storage**

Используется для хранения данных на устройстве с помощью Hive.

**REST API**

Используется для получения данных пользователей.

# Экраны приложения

## Авторизация

Пользователь вводит **email** и **пароль**.

Перед входом выполняется проверка корректности введённых данных.

## Регистрация

Пользователь указывает:

* имя;
* username;
* email;
* пароль.

Выполняется валидация всех полей.

## Список чатов

На экране отображаются существующие диалоги пользователя:

* имя собеседника;
* последнее сообщение;
* время сообщения;
* количество непрочитанных сообщений.

## Диалог

Пользователь может:

* просматривать историю сообщений;
* отправлять новые текстовые сообщения.

## Новый чат

Экран позволяет выполнить поиск пользователей и открыть новый диалог.

Данные пользователей загружаются через **REST API**.

## Профиль

На экране отображается информация о пользователе.

Также доступна функция **выхода из аккаунта**.

# Локальное хранение

Для локального хранения данных используется библиотека **Hive**.

История сообщений сохраняется локально на устройстве и восстанавливается после перезапуска приложения.

Сохраняемые данные включают:

* историю сообщений;
* состояние авторизации.

---

# REST API

Для получения списка пользователей используется REST API **JSONPlaceholder**.

HTTP-запросы выполняются с помощью библиотеки **Dio**.

## Endpoint

```http
GET https://jsonplaceholder.typicode.com/users
```

Полученные данные преобразуются в модели `User` и отображаются на экране создания нового чата.

### Схема работы

```text
NewChatScreen
      ↓
NewChatViewModel
      ↓
UserRepository
      ↓
ApiService
      ↓
JSONPlaceholder API
      ↓
User
      ↓
NewChatScreen
```

---

# Обфускация

Для защиты release-сборки от простого анализа исходного кода используется встроенная возможность обфускации Flutter.

Команда сборки:

```bash
flutter build ios --release \
  --obfuscate \
  --split-debug-info=build/debug-info
```

Параметр `--obfuscate` выполняет обфускацию кода.

Параметр `--split-debug-info` сохраняет отладочную информацию отдельно от приложения.

# Установка на iPhone

Для запуска приложения на физическом iPhone необходимо:

1. Подключить iPhone к Mac.
2. Открыть проект `ios/Runner.xcworkspace` в Xcode.
3. Настроить подпись приложения.
4. Выбрать физический iPhone в качестве устройства.
5. Выполнить release-сборку.
6. Установить приложение на устройство.

После установки release-версии приложение может запускаться непосредственно с домашнего экрана iPhone.
